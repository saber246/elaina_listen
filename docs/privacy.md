# 听阅隐私说明

适用版本为听阅 0.2.0。

您在普通网页上点击听阅时，扩展读取该网页中可提取的标题、正文、语言和来源，并在当前 Edge 配置中保存一份本地阅读记录。扩展根据网页地址生成用于识别文章的摘要，阅读库保存该摘要和来源域名。阅读库还保存您打开文章的时间、收藏状态和朗读段落。主题偏好同样保存在当前 Edge 配置。

使用右键菜单朗读选区时，扩展使用 Edge 返回的选中文字，并尝试获取该区域的语言。选区内容只在浏览器会话里暂存，关闭该阅读页后清除。

朗读由设备上的本机系统语音完成。扩展没有帐号和遥测功能，也不会把正文、选区、阅读记录或设置上传到外部服务。本地记录由当前 Edge 配置保管，扩展不作为无痕模式下的阅读工具运行。

在阅读库中使用「移除记录」可删除对应文章快照、历史、收藏与进度。卸载扩展时，Edge 会清除该扩展的本地存储。
