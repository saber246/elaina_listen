## 商店描述

用听阅把网页整理成适合阅读和朗读的页面。在桌面 Microsoft Edge 上打开新闻、博客或长文，点击工具栏中的听阅，扩展会提取标题和正文，尽量去掉导航与侧栏。阅读页使用设备已有的本机系统语音，可以播放、暂停、继续、停止、切换段落和调整语速。读到的位置会在页面中显示。支持语音边界的设备会高亮当前句子，其他设备会高亮当前段落。

只想听几行时，可以选中文字、点右键，再用听阅打开单独的选区阅读页。完整文章会记录在本地阅读库，可在历史与收藏中随时找到，关掉阅读页后仍可从之前的段落继续。阅读界面提供浅色和深色模式。

听阅不需要注册帐号或安装额外朗读模型，文章和阅读记录留在当前 Edge 配置中。使用前请确认设备已安装与文章语言匹配的系统语音。部分动态页面可能无法完整提取，可改用右键选区朗读。

## 隐私表单要点

| 字段 | 填写内容 |
| --- | --- |
| 单一用途 | 将用户主动选定的网页正文或文字转成便于阅读和朗读的本地内容，并保留本地阅读位置。 |
| `activeTab` | 点击听阅时临时访问正在处理的网页。 |
| `scripting` | 对当前页提取正文，或判断选区使用的语言。 |
| `storage` | 本地保存文章、收藏、历史、进度和主题，暂存当前阅读页数据。 |
| `contextMenus` | 为选中文字和扩展图标提供右键入口。 |
| 远程代码 | 扩展运行所用的脚本与依赖全部随扩展包提供。 |
| 数据处理 | 按 `privacy.md` 如实披露网页内容和阅读活动的本地处理。确认最终表单与发布包一致。 |

## 给审核人员的测试说明

1. 使用装有简体中文本机语音的 Windows 设备，在桌面 Edge 打开一篇中文新闻或博客，点击听阅图标。
2. 在阅读页点击「播放」，验证段落高亮、暂停、继续、跳段和调速。用另一种本机语音测试时，句子边界支持程度可能不同。
3. 加入收藏，跳到第二段，再关闭阅读页。右键点击工具栏听阅图标，选择「打开听阅阅读库」，从「收藏」打开文章并验证续读位置。
4. 在原网页选中几句话，右键选择「用听阅朗读选中文字」，在新的阅读页点击「播放」。
5. 切换深色模式并重新打开阅读页。若要测试断网朗读，先打开阅读页，再断网测试已安装的本机语音。
