# elaina listen 手机端

手机端使用浏览器提供的本机系统语音。文章、收藏、朗读位置和导入的音频保存于当前设备的浏览器或已安装的 PWA。

## 在电脑预览

在仓库根目录启动本地静态服务器。

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

用浏览器打开 `http://localhost:8765/mobile/`。页面显示「离线资源已就绪」后，可以断网刷新并检查阅读库。

## 在手机上安装

将 `mobile/` 和 `extension/speech.js`、`extension/timeline.js` 按仓库中的相对位置放到同一 HTTPS 静态站点，手机打开该站点的 `/mobile/`。首次访问需联网，让应用缓存页面资源。

- iPhone 在 Safari 分享菜单里选择「添加到主屏幕」。
- Android 在浏览器菜单里选择「安装应用」或「添加到主屏幕」。

## 使用

- 「粘贴文章」可填标题和正文。「导入文件」支持 TXT 和浏览器可播放的音频。TXT 支持 UTF-8、带 BOM 的 UTF-16，以及 GB18030。
- 文章点播放后会使用设备提供给浏览器的语言对应本机音色。语音列表会随系统语言和音色设置变化。若提示找不到匹配语音，检查手机的语音设置。
- 音频会存入当前设备，可以在飞行模式下打开并续听。实时系统朗读的锁屏表现取决于手机和浏览器。
