# elaina

「elaina」是桌面 Microsoft Edge 阅读扩展。它把网页正文整理到独立阅读页，用设备上的本机语音朗读，并在本地保存完整文章和朗读位置。

## 运行

1. 在 Edge 打开 `edge://extensions`，开启「开发人员模式」。
2. 选择「加载解压缩的扩展」并选中 `extension` 文件夹。已加载阶段 1 的用户可以在原扩展卡片点「重新加载」。
3. 打开普通网页文章，点击工具栏扩展菜单里的「elaina」，然后点击「播放」。打开后可把 elaina 固定到工具栏。

## 验收

- 分别打开普通新闻、博客和长文。确认阅读页里有标题和正文，主要导航和侧栏被排除。
- 试播、暂停、继续、上一段、下一段和停止。拖动语速滑块并切到下一段，确认新语速生效。拖动进度条可预看并跳到新位置；拖动结束才会跳播。页面会显示按文字量与所选语速估算的总秒数和剩余时间。朗读中，提供可靠句子边界的语音会高亮当前句，其他语音会高亮当前段。
- 选中网页文字并右键选择「用 elaina 朗读选中文字」，在阅读页点击「播放」。阅读库只记录完整文章。
- 收藏一篇完整文章，切到第二段后关闭阅读页。右键点击工具栏 elaina 图标打开阅读库，从「收藏」重新打开文章，验证可从第二段继续。「历史」里可查看打开过的文章并移除条目。
- 切换深色模式，关闭阅读页后重新打开，验证主题选择保留，按钮显示下一步可切换的主题。用 Tab 和 Enter 操作主要控件。
- 用装有对应本机语音包的设备，在打开阅读页后断网试播。受限页、正文为空和没有合适的本机语音时，应显示相应提示。

## 文件结构

- `extension/` 是可直接加载的 Manifest V3 扩展。正文提取使用随包分发的 Mozilla Readability 0.6.0。
- `docs/privacy.md` 与 `docs/store-listing.md` 是商店提交材料。
- `docs/store-assets/` 存放 Edge Add-ons 列表素材。项目根目录的 `elaina-edge-0.2.1.zip` 是扩展上传包。
