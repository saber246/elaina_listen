# elaina listen

「elaina listen」是桌面 Microsoft Edge 阅读扩展，项目代号 `elaina_listen`。它把网页正文整理到独立阅读页，用设备上的本机语音朗读，并在本地保存完整文章和朗读位置。

## 运行

1. 在 Edge 打开 `edge://extensions`，开启「开发人员模式」。
2. 选择「加载解压缩的扩展」并选中 `extension` 文件夹。已加载同一目录的旧版扩展时，在原扩展卡片上点击「重新加载」，保留阅读库。
3. 打开普通网页文章，点击工具栏扩展菜单里的「elaina listen」，然后点击「播放」。打开后可把它固定到工具栏。

## 本机语音包

1. 双击 `desktop/start-voice-packs.cmd`。看到「本机语音助手已就绪」后保持窗口开启。如果已有旧版宵宫助手在运行，先关闭旧窗口。启动器优先使用当前开发机的 `D:\onnx_train\venv`，其他电脑使用 PATH 里的 Python。助手需要 `numpy` 和 `sherpa-onnx`，已用 sherpa-onnx 2.0.2 测试。
2. 在 Edge 重新加载扩展并打开一篇文章，点播放器里的「语音包」。选择「下载」可从 sherpa-onnx 的 GitHub 发布页获取 Matcha、MeloTTS 或 Kokoro。下载完成后点「使用」，再点击「播放」。语音包下载时需要联网，下载后在本机运行。
3. 默认会识别项目同级 `models` 目录中的已有模型。宵宫使用 `models/yoimiya`，凡尘使用 `models/fanchen-c` 或 `models/vits-zh-hf-fanchen-C` 下已解压的文件。下载内容保存在 `desktop/voice-packs/`。可以用 `--models-dir` 和 `--download-dir` 指定其他位置。

加载同一项目目录的解压扩展时，助手会自动计算扩展 ID。使用其他安装方式时，启动器接受 `--extension-id` 和 Edge 扩展卡片上的 ID。旧版 `start-yoimiya.cmd` 仍接受宵宫目录、Python 路径和扩展 ID 作为位置参数。

助手只监听 `127.0.0.1:43167`。只有点击下载时会向上游请求模型文件，文章文本在本机合成。使用系统语音时可以关闭助手。

## 验收

- 分别打开普通新闻、博客和长文。确认阅读页里有标题和正文，主要导航和侧栏被排除。
- 试播、暂停、继续、上一段、下一段和停止。拖动语速滑块并切到下一段，确认新语速生效。拖动进度条可预看并跳到新位置；拖动结束才会跳播。页面会显示按文字量与所选语速估算的总秒数和剩余时间。朗读中，提供可靠句子边界的语音会高亮当前句，其他语音会高亮当前段。
- 选中网页文字并右键选择「用 elaina listen 朗读选中文字」，在阅读页点击「播放」。阅读库只记录完整文章。
- 收藏一篇完整文章，切到第二段后关闭阅读页。右键点击工具栏图标打开阅读库，从「收藏」重新打开文章，验证可从第二段继续。「历史」里可查看打开过的文章并移除条目。
- 切换深色模式，关闭阅读页后重新打开，验证主题选择保留，按钮显示下一步可切换的主题。用 Tab 和 Enter 操作主要控件。
- 用装有对应本机语音包的设备，在打开阅读页后断网试播。受限页、正文为空和没有合适的本机语音时，应显示相应提示。

## 文件结构

- `extension/` 是可直接加载的 Manifest V3 扩展。正文提取使用随包分发的 Mozilla Readability 0.6.0。
- `docs/privacy.md` 与 `docs/store-listing.md` 是商店提交材料。
- `docs/store-assets/` 存放 Edge Add-ons 列表素材。项目根目录保留了 0.3.0 的扩展上传包。测试新版请从 extension 目录加载。

## 手机端

手机端从 `mobile/` 打开，可用设备系统语音朗读文章，并在本机保存收藏、进度和已导入的音频。预览和 HTTPS 安装方式见 [手机端说明](mobile/README.md)。
